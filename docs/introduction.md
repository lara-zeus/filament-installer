## Introduction

@zeus installer is a fork of Laravel Installer with Filament setup support, including default panel creation and initial user setup.

**[Github](https://github.com/lara-zeus/installer) · [Packagist](https://packagist.org/packages/lara-zeus/installer) · [Discord](https://discord.com/channels/883083792112300104)**

## Features

- Creates a new Laravel app from CLI
- Installs Filament with a default `admin` panel
- Creates an initial admin user during setup
